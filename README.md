## CN2 GIA、9929、CMIN2 在实际访问里差在哪

CN2 GIA 是电信的高端回程，9929 是联通的精品网，CMIN2 走移动。三家运营商各有一条自己认的优化路径，商家能做的是把回程接到其中一条或几条上，去程和回程未必对称。

第三方测评给出的参考区间大致是这样：德国机器走 9929 或 CN2 优化回程，国内访问延迟落在 120 到 200ms，普通国际线路在 180 到 220ms；北方联通用户表现常常更好一些。这是测评口径，不是商家承诺。香港和日本机房能压到 30 到 50ms，德国在物理距离上先输一截。

端口数字要单独看。500Mbps 是峰值，共享带宽的产品，商家通常只保证一定比例的时段能跑到标称值，晚高峰掉速属于常态。回程绕路的时候，端口再大也换不来更快的打开速度。

## 几个常被问到的问题

**500Mbps 能跑满吗？** 共享带宽下跑不满是正常的，商家一般只保证多数时段达到标称峰值，晚高峰波动属于预期内。真拿这个数字去投诉，通常得不到处理。

**应该先月付还是直接年付？** 第一次买先月付一个月，测自己所在城市的回程路由和晚高峰速度，满意了再转年付。年付价更低，但退款条款往往也更紧。

**续费会不会涨？** 取决于下单页写的续费价。有些商家是循环折扣，续费与首单同价；有些是首年特价，第二年回到原价。这一栏不看清楚，年付的便宜只是纸面上的。

**能拿来做跨境访问节点吗？** 这类用途在德国商家那里普遍被禁，发包、BT、网盘也在禁止清单上，查到停机且不退款。
